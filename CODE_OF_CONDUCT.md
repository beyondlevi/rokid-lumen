# Code of Conduct

Rokid Lumen follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: we want taking part in this project to be a harassment-free experience for everyone,
whatever their age, body size, visible or invisible disability, ethnicity, sex characteristics,
gender identity and expression, level of experience, education, socio-economic status,
nationality, personal appearance, race, caste, colour, religion, or sexual identity and
orientation.

- Be kind and respectful, accept constructive criticism, and focus on what is best for the
  community.
- Harassment, insults, sexualised language or imagery, personal or political attacks, and
  publishing others' private information are not acceptable.

The full text, including how it is enforced, is at the link above and applies to every space
of this project: issues, pull requests, discussions and reviews.

## Reporting

Report behaviour that breaks this code to the maintainer, Levi Nóbrega, through GitHub
([@beyondlevi](https://github.com/beyondlevi)). For anything that shouldn't be public, use the
contact on that GitHub profile rather than an issue. Every report is reviewed and handled in
confidence.
